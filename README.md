Nexora AI — Landing Page

About

Nexora AI is a modern, responsive landing page for a conceptual artificial intelligence startup.

Technologies Used

- HTML5
- CSS3
- CSS Flexbox and Grid
- CSS Animations
- Responsive Media Queries

Features

- Modern AI-inspired user interface
- Sticky navigation bar
- Hero section with call-to-action buttons
- Features section with three feature cards
- About and Contact sections
- Smooth scrolling navigation
- Responsive layout for desktop and mobile screens

How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open "index.html" in a web browser.

Project Structure

- "index.html" — Website structure
- "style.css" — Website styling and responsive design
- "README.md" — Project documentation
